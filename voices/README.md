# voices/

声の置き場。**中身はリポジトリに入れない。環境ごとに登録し直す。**

リファレンス音声は個人の声そのもので、ディレクトリ名にも名前が付く。
公開リポジトリに載せるものではないため、`.gitignore` でこのファイル以外を除外してある。

## 構成

```
voices/
├── README.md          これ。これだけが追跡される
├── <音声の名前>/
│   ├── ref.wav        リファレンス音声
│   └── voice.yaml     話速・ステップ数など。無くてよい
└── <別の名前>/
    └── ...
```

`<音声の名前>` がそのまま管理UIとログに出る。日本語も使える。

## 登録のしかた

管理UI `http://127.0.0.1:8080/admin` の「新しい音声の名前」に名前を入れ、
wav を選んで「追加」する。エクスプローラで直接置いた場合は「voices/ を再スキャン」を押す。

リファレンス音声は **数秒〜十数秒の、雑音の少ない読み上げ**でよい。
通常は書き起こし（キャプション）を用意する必要はありません。

## voice.yaml

無くてもよい。書けば音声ごとに生成パラメータを固定できる。

```yaml
display_name: 表示名        # 省略時はディレクトリ名
duration_scale: 0.8        # 話速。小さいほど速い
num_steps: 24              # 生成ステップ数。小さいほど速いが音質が落ちる
seed_raw: 12345            # 良い出力の seed を見つけたら固定する
```

管理UIの試聴で聴き比べてから「この設定を保存」で書き込める。手で編集してもよい。

## default

`default` という音声は、ディレクトリが無くても常に存在する。
リファレンス音声なしの、モデル既定の声になる。声を1つも登録していなくても動作は確認できる。
