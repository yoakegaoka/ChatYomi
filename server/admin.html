はじめて使う方へ
  1. 下の「声を試す」で読み上げを確認します。声を登録しなくても試せます。
  2. ブラウザに読み上げ機能を追加します。
  3. Claude、Copilot、Gemini、ChatGPTで丸いボタンを押し、読み上げを有効にします。

初回の音声生成には、モデルの準備で時間がかかることがあります。

読み上げる声

「基本の声」は、サイトごとに声を指定していない場合に使います。

声を追加する

雑音やBGMの少ない、15～30秒の音声を選んでください。ファイルなしでも標準の声をもとに作れます。

声を試す・調整する

空欄なら標準の値を使います。少なくすると生成が速くなりますが、音質が変わります。
