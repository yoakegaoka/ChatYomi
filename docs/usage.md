# 詳しい使い方

初回導入とブラウザへの追加は[Windowsで使い始める](windows-onboarding.md)を参照してください。

## 読み上げボタン

AIチャット画面の丸いボタンをクリックまたはタップすると、読み上げの有効・無効を切り替えられます。読み上げ中に押すと停止します。初回はブラウザの音声再生を許可するため、一度押してください。

右クリックまたは長押しで設定パネルが開きます。ボタンはドラッグで移動でき、位置は保存されます。直前の回答を聞き直すときは設定パネルの「もう一度読む」を選びます。

## 声を登録・選択する

`start.cmd` で起動した後、管理画面（<http://127.0.0.1:8080/admin>）の「声を追加する」で名前と雑音やBGMが少ない15～30秒程度のWAVファイルを選びます。「試聴・調整」で声を確かめ、「基本の声にする」で普段使う声を選びます。声を登録しなくても「標準の声」で動作確認できます。

管理画面の「サイトごとの声」で、ChatGPT、Gemini、Claude、Copilotそれぞれに使う声を割り当てられます。

管理画面上部の「音声サーバーの接続状態」で、ChatYomiとIrodori-TTS-Serverの接続やモデルの読み込み状態を確認できます。モデル名は下部の「詳細設定とヘルプ」→「接続情報」に表示されます。ここに表示されるのはPC側の音声サーバーの状態で、スマートフォンとPC間の接続状態ではありません。

## 読み方を直す

英単語や記号の読み方は、管理画面の「声を試す・調整する」で確認します。自分の環境だけで読み替えたい語は、プロジェクトの `readings.local.yaml` に追加します。

```yaml
words:
  Foo Bar: フーバー
symbols:
  '→': '、'
```

辞書を変更した後は管理画面の「詳細設定とヘルプ」から読み直せます。`readings.local.yaml` には固有名詞が入ることがあるため、他人へ配布するフォルダーには含めないでください。

## Androidで使う

先にPCで読み上げを確認します。声の登録はPCの管理画面で行ってください。Android端末とPCは同じ家庭内ネットワークにつなぎます。

1. PCで `stop.cmd` を実行します。ChatYomiのフォルダーにある `config.yaml` を開き、`host: 0.0.0.0` に変更します。`api_token:` の右側には、推測されにくい20文字以上の英数字を入れます。`change-me` は使わず、設定した値を控えてください。保存後、`start.cmd` で起動します。
2. Windowsの「PowerShell」を管理者として開き、次のコマンドで家庭内ネットワークからの接続を許可します。この操作は一度だけ行います。

   ```powershell
   New-NetFirewallRule -DisplayName "TTS読み上げサーバ" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow -Profile Private
   ```

3. PCの「設定」→「ネットワークとインターネット」で、接続中のネットワークの「IPv4 アドレス」を確認します。AndroidのFirefoxで `http://<PCのIP>:8080/health` を開き、`status` が `ok` と表示されることを確かめます。`<PCのIP>` は確認した数字に置き換えます。
4. AndroidのFirefoxにViolentmonkeyを追加します。同じブラウザで `http://<PCのIP>:8080/tts-readaloud.user.js` を開き、表示されたインストール画面から追加します。ここまではAPIトークンの入力は不要です。
5. AndroidでAIチャットを開き、丸いボタンを長押しします。設定パネルの「APIトークン」に、手順1でPCの `config.yaml` に設定した**同じ値**を入力します。「テスト読み上げ」で音を確認し、「保存して閉じる」を押します。丸いボタンを一度押して読み上げを有効にします。

`/health` が開けない場合は、PCのIPアドレス、ChatYomiの再起動、ファイアウォールを確認してください。スクリプトのインストール画面が出ない場合はViolentmonkeyが有効か確認します。インストール後に `HTTP 401` と表示される場合は、Androidに入力したAPIトークンを確認してください。家庭内ネットワークの外からの利用は、この手順の対象外です。

## 読み上げ対象

既定では通常の文章を読みます。コードブロック、表、Web検索の出典、思考ブロックの見出しは読み飛ばします。設定パネルで一部の扱いを変更できます。

画像・動画・対話型の部品などが埋め込まれた回答は、本文の構成によって音声が出ない場合があります。通常の文章の回答でも音が出ない場合は、設定パネルの「診断」を確認してください。
